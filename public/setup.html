1Start the server

Install Node.js version 18 or newer if you don't have it. Unzip the AuthorTrail download, open a terminal in the authortrail folder, and run:

node server.js

You should see AuthorTrail running at http://localhost:3000. Open that address in your browser. Keep the terminal open while you use AuthorTrail.

2Turn on the AI coach (optional)

The coach turns your originality score into personal advice. It needs an Anthropic API key. Stop the server (Ctrl+C) and start it again with the key:

$env:ANTHROPIC_API_KEY="your-key"; node server.js
ANTHROPIC_API_KEY=your-key node server.js

Replace your-key with your own key. Never share it or save it in a file you send to others. When it works, the AI coach line above turns green.

3Write your first document

  1. Open Sign up and create your account. You will be taken to the Dashboard.
  2. Choose New document.
  3. Write in the editor. Progress is saved automatically about every 30 seconds, or press Save checkpoint.
  4. Watch the Originality score in the side panel. Press Ask AI coach for advice.

4Connect VS Code

  1. Find the vscode-extension folder inside the download.
  2. Copy it into your VS Code extensions folder with the name authortrail.authortrail-0.1.0: 
    Copy-Item -Recurse vscode-extension "$env:USERPROFILE\.vscode\extensions\authortrail.authortrail-0.1.0"
    cp -r vscode-extension ~/.vscode/extensions/authortrail.authortrail-0.1.0
  3. Restart VS Code and open the project you want to track.
  4. Press Ctrl+Shift+P (Cmd+Shift+P on Mac), run AuthorTrail: Start tracking this workspace, and paste your connection code when asked.
  5. Work as usual. The status bar shows your checkpoints, and the project appears on your Dashboard.
  6. To prove your final code later, run AuthorTrail: Export reveal file and give that file to your reviewer.

5Connect your browser

  1. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  2. Choose Load unpacked and select the browser-extension folder.
  3. Click the AuthorTrail icon, paste your server address and connection code, then Save settings.
  4. Open the page you write in and press Track this tab. Then write in any text box.

Editors that draw their own text, such as Google Docs, may be tracked only partly.

6Share and verify a record

  1. On the Dashboard, choose Record next to a document. Copy the page address and send it to your reviewer.
  2. The reviewer sees the integrity stamp, the originality score and the writing timeline. Their browser re-checks the whole chain.
  3. To prove a specific version, send your reveal file (from the editor or VS Code). The reviewer loads it under "Is this the version the author worked on?" and gets a clear answer.
  4. Use Save certificate as PDF on the record page for a printable copy.

The server must be reachable by your reviewer. On your own computer, only you can open localhost links.

7Use the classroom

Teachers:

  1. Open Classroom, name your class and choose Create class.
  2. Give students the six-character join code.
  3. Open the class to see each submission with its originality score, integrity check and flags. Choose Export CSV to save the table.

Students: on the Dashboard, choose Submit to class beside a document, then enter the join code and your name. Work done after you submit is flagged for your teacher.

Help

The page says the server is not running

Run node server.js in the authortrail folder and keep that terminal open.

Hashing or saving fails in the editor

Open the app at http://localhost:3000, exactly. Other addresses without https block the browser's hashing.

The AI coach says it is not set up

Restart the server with your key, as in step 2.

VS Code or the browser cannot reach the server

Check the server address in the extension settings, and that the server is running.

My documents do not appear on the Dashboard

Make sure the connection code in the extension matches the one on this page.
