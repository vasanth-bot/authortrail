API reference

All endpoints are JSON over HTTP. Owner keys go in x-owner-token, connection codes in x-library-code.

EndpointAccessPurpose
POST /api/docsOpenCreate a document. Returns the id and owner key.
POST /api/docs/:id/checkpointsOwner keyAdd a checkpoint: content hash and statistics.
GET /api/docs/:idPublic, or author, teacher, or ?k= share keyChain, integrity, originality score, suggestions.
GET /api/docs/:id/proof/:iAs aboveMerkle proof for one checkpoint.
GET /api/docs/:id/anchorAs aboveDigest to stamp with an external timestamp service.
POST /api/docs/:id/settingsAuthorSet visibility and the AI use declaration.
POST /api/docs/:id/shares and /revokeAuthorCreate an expiring share link, or revoke all.
POST /api/docs/:id/deleteAuthorDelete the record.
GET /api/library/:codeConnection codeList documents linked to a code.
GET /api/insightsConnection codeDaily activity, streak and totals.
POST /api/ai/coachAuthorPersonalised coaching (needs a server API key).
POST /api/classes, GET /api/classesConnection codeCreate and list classes.
POST /api/classes/joinAuthor of the documentSubmit a document to a class by join code.
GET /api/classes/:id and /csvClass ownerSubmissions with flags, as JSON or CSV.
GET /api/statusOpenServer and AI coach status.

Example

curl -X POST http://localhost:3000/api/docs -d '{"title":"My essay"}'
